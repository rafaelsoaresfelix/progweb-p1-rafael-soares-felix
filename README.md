## Sobre o projeto

Repositório destinado às atividades da disciplina de Programação Web.

## Modelagem de classes — Sistema de Agendamento de Consultas

A modelagem representa um sistema para agendamento de consultas entre pacientes e profissionais, com suporte ao envio de notificações. O modelo aplica os princípios SOLID, com foco em Responsabilidade Única (SRP) e Inversão de Dependência (DIP).

Consulte o documento completo em [MODELAGEM.md](MODELAGEM.md).
